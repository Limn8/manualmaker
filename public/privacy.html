개인정보처리방침

시행일: 2026년 7월 10일

매뉴얼 메이커는 화면 캡처 이미지로 매뉴얼을 만드는 웹 도구입니다. 사용자가 만든 프로젝트와 이미지는 기본적으로 사용자의 브라우저 안에 저장되며, 별도의 회원가입이나 서버 데이터베이스 수집 기능을 제공하지 않습니다.

1. 처리하는 개인정보

매뉴얼 메이커는 회원가입, 로그인, 결제 기능을 제공하지 않으며 이름, 이메일, 연락처 같은 개인정보를 직접 입력받지 않습니다. 다만 사용자가 직접 캡처하거나 업로드한 이미지 안에 개인정보가 포함될 수 있으므로, 매뉴얼 제작 전 민감한 정보가 노출되지 않도록 확인해 주세요.

2. 브라우저 저장소 사용

제작 중인 매뉴얼 프로젝트는 편집 편의를 위해 사용자의 브라우저 저장소(IndexedDB)에 저장될 수 있습니다. 이 데이터는 사용자의 기기와 브라우저에 남으며, 브라우저 사이트 데이터 삭제 기능으로 삭제할 수 있습니다.

3. 권한 사용

  • 화면 캡처: 사용자가 화면 캡처 버튼을 누를 때 선택한 화면이나 창을 이미지로 가져오기 위해 사용합니다.
  • 클립보드: 사용자가 클립보드 버튼 또는 붙여넣기를 사용할 때 이미지 데이터를 가져오기 위해 사용합니다.

4. 제3자 제공 및 외부 전송

매뉴얼 메이커는 사용자가 만든 매뉴얼 데이터를 별도 서버로 전송하거나 제3자에게 제공하지 않습니다. 단, 사이트 제공을 위해 Vercel 등 호스팅 사업자의 기본 접속 로그가 처리될 수 있습니다.

5. 문의

문의가 필요한 경우 제작자 페이지를 통해 연락해 주세요.

이 방침은 서비스 기능 변경이나 법령 변경에 따라 수정될 수 있습니다.
